# CrossApp

Наскрізний проєкт з практикуму крос-платформного програмування.

## Предметна область

- **Назва**: Склад
- **Сутності**: `Product` (товар), `StockBatch` (партія), `Warehouse` (склад), `Movement` (переміщення)
- **Призначення**: Облік залишків товарів за партіями та відстеження їх переміщення між складами.

## Структура solution

- `src/Core` — бібліотека класів (спільна бізнес-логіка, доменні моделі, збір системної інформації)
  - `Core/Dto/` — майбутні DTO-моделі (тиждень 3)
  - `Core/Domain/` — майбутні сутності з бізнес-правилами (тиждень 4)
  - `Core/Storage/` — сховища та репозиторії (тиждень 5)
- `src/Cli` — консольний інтерфейс користувача (точка входу, відображення даних)

## Команди для роботи

### Збірка та звичайний запуск

````bash
dotnet build
dotnet run --project src/Cli


### Публікація
```bash
# Self-contained (автономний бінарник із копією runtime)
dotnet publish src/Cli -c Release -r win-x64 --self-contained true

# Framework-dependent (лише бінарники коду, потрібен встановлений .NET)
dotnet publish src/Cli -c Release -r win-x64 --self-contained false


### Прямий запуск зібраного застосунку
```bash
./src/Cli/bin/Release/net10.0/win-x64/publish/Cli.exe


## Порівняння режимів публікації

| RID | Режим | Розмір publish | Потрібен runtime |
| :--- | :--- | :--- | :--- |
| `win-x64` | self-contained | ~70-80 МБ | ні |
| `win-x64` | framework-dependent | ~0.2-0.5 МБ | так (.NET 10) |

> **Різниця режимів**: `self-contained` містить повноцінне середовище .NET Runtime та системні бібліотеки, що дозволяє запускати програму на чистій системі, але суттєво збільшує розмір папки. `framework-dependent` містить лише зібраний код застосунку і потребує наявності попередньо встановленого .NET 10 на комп'ютері користувача.

## Середовище
- .NET SDK 10.0
- Windows 11 x64
````
